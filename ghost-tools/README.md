# ghost tools

Software that collects, uses, and publishes [Ghost](../README.md). Source code belongs inside Ghost alongside the records it works with.

- [browser](browser/README.md): macOS browser and selected browsing capture.
- [video-process](video-process/README.md): prompt-driven process documents and versioned native HDR video previews.
- [lotus-study](lotus-study/README.md): lotus animation and media studies.
- [personhood-scene](personhood-scene/README.md): Blender scenes and rendering tools.
- [publishing](publishing/README.md): approved publishing of source, private assets, and the personal site.

Authentication, browser profiles, dependencies, and build products remain local and untracked. Tools write artifacts into Ghost without rewriting existing records or personal annotations.
