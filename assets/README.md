original images, audio, videos, and other media referenced throughout ghost belong here.

keep each asset once and preserve its original filename where practical. the referring note or record carries its context and any reflections. moving media for organization must preserve the media itself and its references.

Media bytes stay local and are backed up privately to R2 by the [publish workflow](../ghost-tools/publishing/README.md). Git tracks `manifest.json`, which maps the unchanged local filenames to checksums and private object keys. The archive is not exposed through the personal site.
